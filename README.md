# Data Analysis of Two Nations

## Overview
This project analyzes and compares key development indicators of two countries using data analysis techniques.

## Objective
To identify differences and similarities between two nations based on economic and social factors.

## Tools Used
- Python
- Excel
- Pandas, NumPy
- Matplotlib / Seaborn

## Workflow
- Data Cleaning
- Data Analysis
- Visualization
- Comparison of Results

## Results
The analysis highlights key differences and trends between the two nations, helping to understand their development patterns.

## Conclusion
This project demonstrates how data analysis can be used to compare and interpret real-world country data.
